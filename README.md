# Cybersecurity Lab Environment Setup

## Project Overview
This project documents the setup of a cybersecurity testing lab using Oracle VirtualBox and Kali Linux.

## Week 1 – Project Module 1
**Task:** Setup a Cybersecurity Testing Lab Environment.

## Tools Used
- Oracle VirtualBox
- Kali Linux
- 7-Zip
- Windows 11 (Host Operating System)

## Lab Configuration
- Virtualization Platform: VirtualBox
- Virtual Machine: Kali Linux
- Network Mode: NAT Network
- Network Subnet: `10.0.0.0/24`
- Kali Linux IP Address: `10.0.0.2/24`
- Internet Access: Enabled
- Shared Folder: Host `/downloads` folder
- Clipboard and Drag & Drop: Enabled

## Implementation Steps
1. Installed 7-Zip.
2. Installed Oracle VirtualBox.
3. Created a NAT Network with the `10.0.0.0/24` subnet.
4. Downloaded and imported Kali Linux into VirtualBox.
5. Configured the Kali Linux network settings.
6. Enabled shared folders, clipboard and drag-and-drop.
7. Tested internet connectivity.
8. Created a virtual machine snapshot.


## Learning Outcomes
- Learned basic virtualization using VirtualBox.
- Understood NAT Network configuration.
- Installed and configured Kali Linux.
- Practiced basic virtual machine networking.
- Created a dedicated environment for ethical hacking and cybersecurity learning.
